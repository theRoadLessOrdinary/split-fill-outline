# Split Fill and Outline

An Inkscape extension. It duplicates each selected object: outline only on the copy on top, fill only on the bottom.

Useful for embroidery, where a shape's fill and its outline are usually sewn as two separate objects.

For a group, every object inside it is changed the same way.

## Menu

Extensions > Map's Edge Tools > General > Paths > Split Fill and Outline

## Install

Copy this folder into your Inkscape user extensions folder and restart Inkscape.

Tested with Inkscape 1.4.
